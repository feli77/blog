## 隱私權政策

> **最後更新**：2025 年 12 月 30 日

本站部署於 Cloudflare Workers 平台。本站高度重視您的隱私，僅蒐集提供基本服務所需的最少資料。本政策將說明本站如何蒐集、使用和保護您的資料。

### 資料蒐集類型

1. 使用者提交的資料
    - 自訂暱稱（未登入使用者必填）
    - 評論資料：包含評論內容及其發布時間戳記。
    - 評論草稿：由使用者撰寫但尚未提交的評論內容草稿。
    - Web Push 訂閱資料：包含訂閱端點資訊。
    - 電子郵件地址（OAuth 登入使用者選填）：使用者個人的電子郵件地址。
    - OAuth 登入資訊（使用者授權登入）：包含第三方平台提供的使用者名稱、顯示名稱、頭像及權杖資料。
    - 個人首頁連結（OAuth 登入使用者選填）
2. 自動蒐集的資料
    - 主題偏好：網站淺色模式或深色模式的偏好設定。
    - 存取記錄資料：包括但不限於 IP 位址、瀏覽器版本、存取時間等，由 Cloudflare 自動產生（詳見 [Cloudflare 隱私權政策](https://www.cloudflare.com/privacypolicy/)）。
    - Cloudflare Turnstile 資料：用於驗證未登入使用者的評論請求（詳見 [Turnstile 隱私權附錄](https://www.cloudflare.com/turnstile-privacy-policy/)）。

### 資料使用目的

- 提供評論服務：蒐集和處理使用者評論資料，包括評論內容、評論草稿、發布時間、使用者暱稱或 OAuth 帳號資訊，以在網站上顯示使用者評論和互動內容。對於 OAuth 登入使用者，還會顯示其認證平台的使用者名稱、顯示名稱和頭像資訊。
- 提升使用者體驗：將使用者的主題偏好設定（淺色／深色模式）儲存在 localStorage 中，確保使用者下次造訪時能保留個人化的介面設定。對於未登入使用者，會將自訂暱稱儲存在 localStorage 中，以便後續評論。
- 通訊與通知：使用 Web Push 訂閱資料傳送桌面推播通知，或使用電子郵件地址傳送郵件通知，及時告知使用者其評論的回覆或其他相關互動資訊。
- 安全防護：使用 Cloudflare Turnstile 服務對未登入使用者進行人機驗證，防止評論濫用和惡意攻擊。
- 內部分析與服務改進：利用 Cloudflare 提供的基本存取記錄資料進行網站效能分析和安全監控，以改善服務品質和使用者體驗。

### 資料儲存與保護

- Cloudflare D1：評論資料、OAuth 登入資訊、個人首頁連結、電子郵件地址和 Web Push 訂閱資料均儲存在 Cloudflare D1 資料庫中。該資料庫提供企業級安全保護，包括資料加密儲存、存取控制和定期備份。所有資料傳輸均透過加密連線進行。
- JWE Cookies：OAuth 身分識別資訊和授權過程中的驗證資料使用 JSON Web Encryption (JWE) 技術加密儲存在 Cookies 中。JWE 提供端對端加密保護，確保敏感認證資訊在傳輸和儲存過程中的安全性。Cookies 設有適當的安全旗標（HttpOnly、Secure、SameSite）。
- localStorage：使用者的自訂暱稱、主題偏好設定和評論草稿儲存在瀏覽器的 localStorage 中。這些資料僅儲存在使用者的本機裝置上，不會傳輸到伺服器。使用者可以隨時透過瀏覽器設定清除這些本機資料。
- HTTPS 加密：本站全站啟用 HTTPS 加密傳輸，所有資料在用戶端與伺服器之間傳輸時均受 TLS/SSL 加密保護，防止資料在傳輸過程中遭竊取或竄改。
- Cloudflare 安全防護：利用 Cloudflare 提供的 DDoS 防護、Web 應用程式防火牆 (WAF)、Bot 管理和威脅情報等安全服務，保護網站和使用者資料免受惡意攻擊。

### 資料共享與揭露

本站承諾保護您的隱私，在以下情況下可能會共享或揭露您的資料：

- 第三方服務供應商：本站使用 Cloudflare 提供的基礎設施服務，您的資料將在 Cloudflare 平台上處理和儲存。
- OAuth 認證平台：當您選擇使用 OAuth 登入時，本站會從您授權的第三方平台取得基本公開資訊。這些資訊僅用於身分驗證和評論顯示，不會與其他第三方共享。
- 法律要求：在法律法規要求或司法機關依法要求的情況下，本站可能需要揭露相關資料。但本站會在法律允許的範圍內，盡力保護使用者隱私並通知受影響的使用者。
- 資料匿名化：本站可能會使用匿名化或去識別化的資料進行統計分析，這些資料不會包含任何可識別個人身分的資訊。

除上述情況外，本站不會向任何第三方出售、出租或以其他方式共享您的個人資料。

身為資料主體，您擁有以下與個人資料相關的權利：

#### 所有使用者

- 您有權瞭解本站蒐集了您的哪些個人資料。
- 您可以隨時清除瀏覽器中儲存的本機資料。
